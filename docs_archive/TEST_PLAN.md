### 测试 1：软件断点 (INT3)

#### 测试用例 1.1：基础断点设置和触发
**目标**：验证 INT3 断点能正确暂停目标进程

**步骤**：
1. 编译测试程序 `LMvtdriverR3Test.exe`
2. 附加调试器到测试程序
3. 在 `main` 函数入口设置断点
4. 继续执行
5. 验证在断点处暂停
6. 查看寄存器和内存
7. 继续执行

**预期结果**：
- 断点命中，显示 `[breakpoint] id=1 hit at 0x...`
- RIP 指向断点地址
- 原始字节已保存
- 继续后程序正常运行

#### 测试用例 1.2：断点重新 arm
**目标**：验证断点命中后能重新激活

**步骤**：
1. 在循环内设置断点
2. 继续执行多次
3. 验证每次循环都能命中断点

**预期结果**：
- 每次循环都暂停
- INT3 在单步执行后重新写入

#### 测试用例 1.3：多个断点
**目标**：验证多个断点可以共存

**步骤**：
1. 在不同地址设置 3 个断点
2. 依次触发每个断点
3. 验证每个断点都能正确命中

**预期结果**：
- 每个断点独立工作
- 断点 ID 不冲突

#### 测试用例 1.4：断点删除
**目标**：验证删除断点后恢复原始字节

**步骤**：
1. 设置断点
2. 删除断点
3. 验证原始字节已恢复
4. 执行到该地址
5. 验证不再暂停

**预期结果**：
- 删除后显示 `[bp] id=X removed`
- 内存恢复原始值
- 不再触发暂停

**预期结果**：

## 测试程序设计

创建一个简单的测试程序 `test_target.cpp`：

```cpp
#include <windows.h>
#include <stdio.h>

void TestFunction() {
    printf("Inside TestFunction\n");
}

int RecursiveFunc(int n) {
    if (n <= 0) return 0;
    return n + RecursiveFunc(n - 1);
}

int main() {
    printf("Test program started\n");
    
    // 测试 1: 基础断点
    printf("Checkpoint 1\n");
    
    // 测试 2: 函数调用
    TestFunction();
    
    // 测试 3: 循环断点
    for (int i = 0; i < 5; i++) {
        printf("Loop iteration %d\n", i);
    }
    
    // 测试 4: 递归调用
    int result = RecursiveFunc(5);
    printf("Recursive result: %d\n", result);
    
    // 测试 5: 变量修改
    int test_var = 100;
    printf("test_var = %d\n", test_var);
    
    // 测试 6: 除零异常（已验证）
    // int zero = 0;
    // int crash = 42 / zero;
    
    printf("Test program finished\n");
    getchar(); // 等待输入，防止立即退出
    return 0;
}
```

## 嵌套 SVM 验证清单

以下测试必须在支持 AMD SVM nested virtualization 的 Windows 虚拟机中执行。每次加载驱动前创建快照，并准备 KD、测试签名和蓝屏回滚方案。

- [ ] L0 普通启动、CPUID/MSR 处理、透明调试器和卸载无回归。
- [ ] 先加载 L0，再加载 `svmtest.sys`：`svmtestctl.exe capabilities` 应显示 `svme_current=0`，其他 EFER 位不因隐藏 SVME 而改变；能力查询不代表嵌套运行成功。
- [ ] 在可回滚环境执行 `svmtestctl.exe run 1`，不应再因初始 SVME 返回 `STATUS_DEVICE_BUSY`；若失败，记录阶段和退出信息。成功后 `result` 应显示 CPUID/VMMCALL 往返成功，再次查询能力应恢复 `svme_current=0`、虚拟 HSAVE 恢复原值。
- [ ] 单次成功后执行 `run 8` 并重复运行，验证 L1 开启和清除影子 SVME 均正常；卸载 `svmtest.sys` 后 L0 仍可继续运行和卸载。若蓝屏，先保存停止码与转储，不将能力查询通过视为验收完成。
- [ ] L1 读取/写入 `IA32_MSR_EFER`、`SVM_MSR_VM_CR`、`SVM_MSR_VM_HSAVE_PA`；验证 `LOCK`、`SVMDIS`、保留位和未对齐地址的结果。
- [ ] L1 执行 `VMLOAD`、`VMSAVE`、`STGI`、`CLGI`、`INVLPGA`；验证 CPL/EFER 不合法时得到 `#GP(0)`。
- [ ] L1 创建不启用 NPT 的 VMCB12 并执行 `VMRUN`；验证 L2 能运行普通代码和 `CPUID`。
- [ ] L1 提供非法 VMCB GPA、非法 MSRPM/IOPM、启用 NPT、无效 ASID、非规范 RIP/RSP；验证只向 L1 注入 `#GP(0)`，不触发 L0 崩溃。
- [ ] L2 触发 CPUID、MSR、异常、CR/DR、IOIO 和 SVM 指令；分别验证反射到 L1、L0 软件处理，以及未知 NPF/VMEXIT 的安全 `#GP` 结果。
- [ ] L2 再次执行 `VMRUN`；验证不进入 L3，收到 `#GP(0)`。
- [ ] 多次进入/退出 L2、修改 VMCB12、反射后继续执行；验证 VMCB12 状态保存区、退出信息、NRIP 和指令字节。
- [ ] L1/L2 反复读写调试寄存器；验证 DR2/DR3/DR7 影子状态与透明调试器原功能隔离。
- [ ] 嵌套运行期间卸载/重新加载驱动；验证所有 VP 退出、MSR 恢复、连续内存释放且无悬挂引用。
